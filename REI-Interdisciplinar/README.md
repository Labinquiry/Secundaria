# REI - Segueix viu el Megalodont?

REI interdisciplinar entre Geologia i Matemàtiques que convida l'alumnat a investigar l'origen i evolució del fons oceànic a partir de la troballa d'una dnt de Megalodont, integrant la modelització matemàtica i la interpretació geològica per qüestionar el món natural.

**Repositori amb el material:** [Enllaç de Github](https://github.com/Labinquiry/Secundaria/tree/main/REI-Interdisciplinar)
